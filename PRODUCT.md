## Platform

## Users

Hiring managers and prospective clients evaluating Depakar B for WordPress development, plugin engineering, and search-focused web work.

## Product Purpose

Present Depakar's work, approach, technical growth, and contact path in a memorable portfolio that turns interest into an interview or project conversation.

## Positioning

A WordPress developer portfolio that connects implementation with discoverability: custom development, plugin engineering, technical SEO, AEO, GEO, performance, and measurement.

## Operating Context

Visitors browse a responsive, public, Vercel-hosted static website. They can explore selected work, personal approach, plugins, and contact Depakar through an email-backed enquiry form.

## Capabilities and Constraints

- Multi-page static website compatible with GitHub and Vercel.
- Sticky navigation, responsive layout, footer, and contact form.
- Formspree is the selected form delivery service; its form ID remains to be added by Depakar.
- Avoid invented client metrics, public releases, testimonials, or credentials.

## Brand Commitments

Depakar B. Professional but current, direct, curious, and technically grounded. Use the supplied portrait and foreground WordPress without limiting the long-term story to WordPress alone.
